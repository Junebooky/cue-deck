# Cue Deck package v1

A single JSON file: schemaVersion: 1; productionId, title, revision; scenes [{id,act,label,number?}]; blocks [{id,sceneId,kind,actor,text}]; frames [{id,blockId,kind,trigger,columns:[{actor,lines:string[]}]}].
Scene and block IDs remain stable across revisions where confidently mapped. Frame order determines displayed cue number. Block order is the source order. A frame anchors to a block; multiple frames may anchor to one block. Preserve full source text in blocks. A later iteration should preserve per-run formatting and source spans/row metadata.
Kinds: blocks lyric/dialogue/nar/direction/place/heading; frames solo/overlap/place/black. Place is a manual transition. Black has no columns; dialogue and NAR never become caption frames. Overlap uses aligned arrays including empty strings as blank rows, 2–3 columns. Shared singing of same text uses solo layout. A red parenthetical guest vocal becomes a localized overlap frame, not a permanent split. Source text and approved display text are separate. All output text white on black, same font size across lanes. Install Pretendard locally for exact font; no external font requests.
Update workflow: receive DOCX/PDF and previous package, inspect run formatting and table alignment, compare additions/deletions/changes, preserve full text, regenerate ordered frames and reviewed trigger anchors, validate, visually review all changes, import as new revision, activate only off-air. Never auto-correct source typos. Ambiguous anchors need human review. Use existing PPTX/CSV as display references; physical timing verified in rehearsal. Actual source files are not part of this public repository.

A whole empty overlap lane is valid when another lane has lyrics. Blocks may have `sourceCells: string[]` for original table row display (empty cells preserved), and optional `sourceRef` for revision traceability. `trigger` is an operator hint, not an automated timing instruction.

## Source-faithful operator reader
Optional block fields: runs [{text,bold?,red?,italic?}], cellRuns (one array of runs per sourceCells entry), number, sourceRef. If provided, text concatenation must exactly match block.text or its original cell text; otherwise import is rejected. Split a multiline lyric paragraph at each original line break for precise anchor positions; for tables, keep rows synchronized and preserve blank cells. Store the immutable input hashes in sourceFiles and reviewStatus (e.g. draft-rehearsal), and verify the source anchors before activation. Audience frames are independent from operator source styling; red runs remain operator-only. Frames can store sourceAnchor, cueNumber, act, sceneNumber, number and notes as provenance. Physical cue timing requires rehearsal even when all textual anchors match.
